**Verdict:** Cloudflare cannot connect to your origin server: the connection was refused (error 521)

- Layer at fault: **server** (confidence high, 85%)

Evidence:

- `HTTP 521 on GET https://cdn-521.ddemo-site.com/ (browser UA)`
- `CDN/WAF detected: Cloudflare`

Likely causes:

- (high) The web server (nginx, Apache, LiteSpeed, IIS) is stopped or crashed.
- (high) The origin firewall blocks Cloudflare's IP ranges (often a security plugin or fail2ban).
- (medium) The server does not listen on port 80/443, or the DNS record points to the wrong IP.

Fix steps:

1. Check that the web server is running and listening on ports 80 and 443.

   nginx:

   ```
   sudo systemctl status nginx
   sudo ss -ltnp | grep -E ':(80|443) '
   ```

   - Verify: The service is active and ports 80/443 are in LISTEN state.
2. Allow Cloudflare's IP ranges in the origin firewall (and in fail2ban/CSF/security plugins).

   firewall:

   ```
   for ip in $(curl -s https://www.cloudflare.com/ips-v4) $(curl -s https://www.cloudflare.com/ips-v6); do
     sudo ufw allow proto tcp from $ip to any port 80,443
   done
   ```

   - Verify: curl -sI --resolve cdn-521.ddemo-site.com:443:ORIGIN_IP https://cdn-521.ddemo-site.com/ from another server returns an HTTP status.
3. Confirm the A/AAAA record in the Cloudflare DNS tab points to the current origin IP.
   - Verify: The IP in Cloudflare DNS matches the server's public IP (curl -4 ifconfig.me on the server).

Could not determine from outside:

- The origin firewall configuration.
