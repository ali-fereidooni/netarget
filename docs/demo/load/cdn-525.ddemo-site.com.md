- **FAIL** `load.cf.525` Cloudflare cannot complete an SSL handshake with your origin over HTTPS (error 525) (`HTTP 525 on GET https://cdn-525.ddemo-site.com/ (browser UA); CDN/WAF detected: Cloudflare`)

**Verdict:** Cloudflare cannot complete an SSL handshake with your origin over HTTPS (error 525)

- Layer at fault: **tls** (confidence high, 85%)

Evidence:

- `HTTP 525 on GET https://cdn-525.ddemo-site.com/ (browser UA)`
- `CDN/WAF detected: Cloudflare`

Likely causes:

- (high) The origin has no valid TLS setup on port 443 (no certificate configured for this hostname, or plain HTTP on 443).
- (medium) The origin does not support SNI or shares no cipher/TLS version with Cloudflare.
- (medium) Cloudflare SSL mode is Full or Full (strict) but the origin only serves HTTP.

Fix steps:

1. Install a certificate for this hostname on the origin (Let's Encrypt or a free Cloudflare Origin CA certificate) and enable TLS on port 443.

   nginx:

   ```
   server {
       listen 443 ssl;
       server_name cdn-525.ddemo-site.com www.cdn-525.ddemo-site.com;
       ssl_certificate     /etc/ssl/cdn-525.ddemo-site.com/fullchain.pem;
       ssl_certificate_key /etc/ssl/cdn-525.ddemo-site.com/privkey.pem;
       ssl_protocols TLSv1.2 TLSv1.3;
   }
   ```

   - Verify: openssl s_client -connect ORIGIN_IP:443 -servername cdn-525.ddemo-site.com </dev/null completes the handshake and shows the certificate ('Verify return code: 0' for a public CA; with a Cloudflare Origin CA certificate, 'unable to get local issuer certificate' is expected).
2. Make sure port 443 on the origin is open to Cloudflare's IP ranges.
   - Verify: openssl s_client (above) connects from an outside server.
3. In Cloudflare → SSL/TLS, use Full (strict) once the origin certificate is valid; do not switch to Flexible to hide the problem.
   - Verify: The site loads over HTTPS with SSL mode Full (strict).
